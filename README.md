# JavaScript DOM Manipulation Practice

Practice with DOM manipulation, events, Fetch API, and dynamic element creation.

## Tasks

### Task 1: DOM 
- Change button text on click.
- Change button color on click.
- Replace image on mouse hover.
- Create a user card on button click:
  - Clicking the heart icon changes its color.
  - Hovering over the birthday shows the user's age.

### Task 2: DOM + Fetch API
- Load a random dog image from the API: [https://dog.ceo/api/breeds/image/random](https://dog.ceo/api/breeds/image/random)
- `Next` button loads a new image.
- Styling for container and button.

### Task 3: Create Elements
- Create a list of news items from an array of objects.
- Add a like button and a delete button for each news item.
- Highlight a news item on click and like on heart click.
- Styling for news items.
